## About The Project

[![Product Name Screen Shot][product-screenshot]](https://example.com)

A dairy-necromancy bullet-hell game. Summon a horde of undead skeleton minions, mow down waves of enemies, and collect milk to strengthen your skeletons.

You play as a necromancer who raises skeleton minions to fight for you, collects exp from defeated enemies, and levels up to choose from a growing pool of upgrades. The tone combines a silly concept of using milk to strengthen skeleton' bones within the dark setting of fighting monsters, performing necromancy rituals, and summoning undead.

This game began as an entry in the Mini Jame Gam 55, but has since grown beyond that scope.

## Getting Started



### Prerequisites

Godot 4
* Download and install Godot 4 at https://godotengine.org/download/

Git LFS for binary asset storage.
* Windows
  * Download the Git LFS installer at https://git-lfs.com/
* Mac
  * Install with homebrew
    ```
    brew install git-lfs
    ```
* Linux
  * On Debian
    ```
    sudo apt-get install git-lfs
    ```
  * On Red Hat
    ```
    sudo yum install git-lfs
    ```
* Set up Git LFS for your user account:
    ```
    git lfs install
    ```

### Installation

* Clone the repo
  ```sh
  git clone https://github.com/Bolsenator/got-milk.git
  ```
* Open project.godot directly in the Godot editor; no separate import step needed.
